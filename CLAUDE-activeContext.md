- **Four agentic patterns adopted (2026-07-26, [ADR-0006](docs/decisions/ADR-0006-agentic-patterns.md)):** reflection · tool use · planning · multi-agent collaboration, recorded as **principles in Tasktracker** (they now surface on every `setActiveTask`). The audit found **two already core, two gaps**. *Planning* is core and **exceeded** — Gate A verifies the plan itself before execution. *Multi-agent* is the premise — the Reviewer is a separate meta-agent, and independence is constitutional. *Reflection* is **partial → R12 (`draft`)**: there is no self-critique before submission, so the first correction opportunity is a Gate B rejection, which is expensive twice over (review often runs a tier *above* the worker, then costs an escalation rung). *Tool use* is **absent → R13 (`draft`)**, the largest gap: `entitlements`/`contextEntitlements` grant **context**, the Context Broker is the sole **context** channel, and `EvidenceBundle.actions` is prose — agents can reason and consult but **cannot act**. Planned as an **Action Broker**, a sibling of the Context Broker. Two constraints carry the decision: **self-review is never self-verification** (no verdict, no skipping Gate B, critique against `acceptanceCriteria` and never the withheld `verificationPlan`) and **tool use is brokered, never direct** (an unmediated call is an unlogged side effect → breaks invariant #1; `blastRadius` gains a second job bounding *which tools are reachable*).
